# Time Tiles

Plan the next **2 hours** as draggable tiles.

- Add tiles (title + minutes + energy)
- Drag to reorder
- Focus mode with a simple countdown ring
- **Share** via permalink (URL hash)
- **Export/Import** JSON
- Saves locally (localStorage)

## Shortcuts

- `Space` — start/pause
- `Enter` — mark done
- `↑/↓` — move selection
